   - GitHub는 단일 파일 **100MB 초과를 시스템에서 엄격히 차단**합니다.
   - 따라서 **1.5GB 이상의 유니티 프로젝트 압축 파일(`*.zip`)**과 **285MB `졸작영상.mov`**는 `.gitignore`로 안전하게 제외 처리되어 있습니다.
   - 덕분에 GitHub Desktop에서 **'Push origin'을 누르시면 충돌이나 에러 없이 즉시 정상 푸시**됩니다.
